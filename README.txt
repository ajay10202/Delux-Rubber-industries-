DELUX RUBBER INDUSTRIES - QUOTATION WEBSITE

Files:
- index.html
- style.css
- script.js
- assets/logo.png

How to use:
1. Extract the ZIP.
2. Keep the assets folder beside index.html.
3. Open index.html in Chrome/Edge.
4. Enter customer and item details.
5. Click Save to keep the latest quotation in the browser.
6. Click Print / PDF and select "Save as PDF" in the print dialog.

Features:
- Dynamic item rows
- Automatic subtotal, discount, CGST, SGST and grand total
- Amount in words
- Quotation number and validity date
- Customer/company details
- Terms and conditions
- Browser local storage
- A4 print/PDF layout
- Responsive mobile layout
